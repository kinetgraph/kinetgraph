# Security acknowledgements

We thank the people who have reported security issues in `kntgraph`.

This list is maintained by the project maintainers. Reporters who
wish to remain anonymous are not listed — the acknowledgement is a
courtesy, not a receipt.

## How to be listed here

Report the issue through the private channel described in
[SECURITY.md](SECURITY.md). Once the advisory is published, the
maintainer adds the reporter's name (or handle) and the CVE, if one
was assigned.
